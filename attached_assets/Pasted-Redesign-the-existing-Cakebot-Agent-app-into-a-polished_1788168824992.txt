Redesign the existing Cakebot Agent app into a polished, premium merchant operating system with an Apple-inspired minimal UI.

First inspect the existing project and understand the current Express backend, API routes, order flow, Razorpay integration, approval flow, audit trail, and fallback parser.

Do not rewrite or remove working backend functionality. Preserve the existing Node.js/Express server and API contract. Make the frontend the main focus. Keep the app runnable with:

npm start

Product concept:

Cakebot is an AI employee for small food businesses. It receives customer orders, understands natural-language requests, checks availability, calculates pricing, applies merchant guardrails, generates optional cake design previews, creates Razorpay payment links, monitors payment confirmation, confirms orders, and deducts a small usage fee from the merchant’s prepaid agent wallet only after successful completion.

Do not implement a crypto wallet. This is an INR prepaid merchant wallet funded through Razorpay.
